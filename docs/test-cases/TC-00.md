## 附：已知的「测不出来 / 不适用」与为什么

| 项 | 为什么 |
|---|---|
| 后端由 `healthy` 转 `unhealthy` 的实际耗时 | 需要停 PG/Redis 后持续观察约 2 分钟；§4.1 里是**推算值**，本项目未实测。要闭合需专门守候一次 |
| `nexus-backend:dev` 镜像体积的绝对判据 | 只给了量级判据（100–150MB 档 vs builder 的 GB 档）；containerd image store 下 `docker history` 可能不全，以体积为准 |
| builder 镜像的首次构建耗时 | 依赖网络与 apt 源，跨机器不可比；本文件不写死数字 |
