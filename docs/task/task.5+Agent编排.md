## 子任务拆解

### 4.1 ReAct Agent 核心
- **输入**：task.3 的 2.2（统一网关）
- **输出**：ReAct 循环（Thought → Action → Observation → 最终答案，设最大迭代次数防死循环）；LangChain4j 或手写
- **依赖**：2.2
- **验收标准**：能按轮次调用工具并最终给出 Final Answer；达迭代上限强制终止

### 4.2 Tools 定义
- **输入**：4.1
- **输出**：`getWeather`、`queryDatabase` 工具（JSON 描述 + 注册表执行）
- **依赖**：4.1
- **验收标准**：模型输出的工具调用指令被正确解析执行，执行结果回填 Observation

### 4.3 多 Agent 协作
- **输入**：4.1、4.2
- **输出**：搜索 Agent + 总结 Agent，通过 `CompletableFuture` 串行编排（模拟 CrewAI）
- **依赖**：4.1、4.2
- **验收标准**：搜索 Agent 输出作为总结 Agent 输入；串行执行日志清晰

### 4.4 对话界面集成
- **输入**：task.3 的 2.4
- **输出**：对话页 Agent 模式入口
- **依赖**：4.3
- **验收标准**：输入"先查一下合肥天气，然后用一句话总结"，Agent 自动按顺序执行并返回总结
