## 子任务拆解

### 3.1 向量存储层
- **输入**：task.1 的 0.1（PG + pgvector）
- **输出**：spring-ai-pgvector-store 集成或手写 pgvector 入库逻辑；知识库 / 文档 / 分块表（db-patch 补丁）
- **依赖**：0.1
- **验收标准**：向量写入后可检索；检索有索引（HNSW / IVFFlat）

### 3.2 文件上传与解析
- **输入**：3.1
- **输出**：文件上传接口 + apache-tika 解析 PDF / Word / TXT
- **依赖**：3.1
- **验收标准**：三种格式均解析出纯文本；大小 / 类型限制与异常处理完善

### 3.3 分块向量化入库
- **输入**：3.1、3.2
- **输出**：Chunk 切分策略 + `nomic-embed-text` 向量化 + 入库（带 tenant_id）
- **依赖**：3.1、3.2
- **验收标准**：分块大小 / 重叠可配置；向量入库有 `log.info` 链路日志；数据租户隔离

### 3.4 知识库问答接口
- **输入**：3.3、task.3 的 2.2
- **输出**：查询接口：问题 → 向量检索 TopK → 拼接 Prompt → 调用网关生成答案
- **依赖**：3.3、2.2
- **验收标准**：检索 TopK 相关分块并拼接 Prompt，答案基于知识库内容生成

### 3.5 知识库前端页面
- **输入**：task.3 的 2.4
- **输出**：知识库管理页（上传 / 文档列表 / 删除）+ 问答入口
- **依赖**：3.2、3.4
- **验收标准**：上传"公司年报.pdf"后提问"去年利润是多少"能准确回答
