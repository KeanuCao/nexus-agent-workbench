## 做了什么

1. **`src/api/kb.ts`**：`uploadDocument` 的 `service.post` 显式补
   `headers: { 'Content-Type': 'multipart/form-data' }`，并重写该处的行内注释（原文是"★ 不要手工设置 Content-Type"，
   方向是反的）。
2. **`src/api/request.ts`**：请求拦截器加一条兜底 —— `if (config.data instanceof FormData) config.headers.delete('Content-Type')`。
3. **给出可复现的硬证据**（不是"应该好了"）：在适配器入口打点，修前 **body = 字符串 `{"file":{}}`（11 字节）**、
   修后 **body = 真 `FormData`**；`vue-tsc` type-check **exit 0**。
4. **上报设计稿与契约互相矛盾**（见下"遇到的坑"第 1 条），没有自行选一条照做。

## 遇到的坑

1. ★ **设计稿本体把方向写反了，且是唯一挂着"待实测确认"的一条。**
   现象：`docs/design/03-RAG知识库.md` §5.1-2 写着"**不要**把 `Content-Type` 写死成 `multipart/form-data`…
   手工写死会**丢掉 boundary**"，而契约 §7.1（已被后端按实测订正）与本次实测都指向**相反**口径
   —— 照设计稿实现就是把这个 415 原样写回来。
   处理：**按更忠实的一条（契约 + 实测）先做，同时把矛盾连同自己的选择一并上报**（CLAUDE.md 的纪律：
   指出矛盾 ≠ 可以停工）。随后由主会话订正设计稿 4 处 + 补 §12 变更记录。
   ⇒ 这条的代价说明：设计稿里**唯一一条"待实测确认"的库行为断言**恰恰是错的 —— 而它比"没写"更有害，
   因为它会主动把人引到反方向。
2. **"axios 会自动删头"这个直觉，需要去源码里定位"它为什么不删"。**
   处理：不信文档、也不停在猜测 —— 读 `node_modules/axios/lib/` 逐行确认两段：
   `defaults/index.js` 的 `hasJSONContentType ? JSON.stringify(formDataToJSON(data)) : data`（先变成字符串）、
   `helpers/resolveConfig.js` 的删头分支判断的是 `data instanceof FormData`（此时已为假 ⇒ 永不触发）。
   再用打点实测互证。**该角色已把"库行为断言先去源码取证"写进自己的记忆文件**
   （`.claude/agent-memory/frontend-engineer/library-behavior-verify-by-source.md`）。
3. **确认"显式写 `multipart/form-data` 不会把 boundary 写死"这一步不能跳过** ——
   这是本次唯一"看起来自相矛盾"的点（一会儿说不能手写、一会儿又必须手写）。
   实测结论：两个适配器（xhr 走 `resolveConfig.js`、fetch 见 `adapters/fetch.js`）都会把**这个不带 boundary 的值**删掉、
   由浏览器补 boundary；**真正不能写的是自拼 `; boundary=…`**。
4. **`el-upload` 的默认 XHR 绕过 axios 拦截器** ⇒ 拦截器里那条兜底对它**无效**，
   所以本页必须用 `:http-request` 自定义（页面已按此实现，见设计 §5.1-1）。两处修复分工因此是：
   显式头（该请求自证意图）+ 拦截器兜底（覆盖其他 `FormData` 调用点）。

## 下次怎么改进

1. **凡是"必须靠某个库的隐式行为"才成立的写法，一律显式写出来**：本次最终写法是
   "显式声明 `multipart/form-data`"（自证）**加**"拦截器对 `FormData` 删头"（兜底）——
   两条互为保险，任何一条单独存在都会让"下一个人改坏它"的成本降到一行删改。
2. **库行为断言 = 源码 + 打点，两样都要**：源码定位"为什么会/不会"，打点给出"实际发了什么字节"。
   只做前者会漏掉版本差异，只做后者说不清机制。本次 **11 字节的 `{"file":{}}`** 就是最有说服力的一句话。
3. **设计稿里凡涉及第三方库行为的句子，实施者要当成"假设"验收，而不是当成"事实"照抄**；
   验完把结论回灌到设计稿（本次由主会话完成订正）。派活时把这条写进要求里。
