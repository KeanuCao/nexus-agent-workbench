## 做了什么

1. **需求**：每条用例在 Allure 报告里带两张**视口**截图（1440×900，用户拍板，**不是**整页）——
   附件名 `执行前` / `执行后`。时机：`执行前` = call 阶段开始（夹具已就绪、**用例体未执行**；
   S1~S3 在用例体内才 `goto` ⇒ 前图是 `about:blank`，**属预期**、已写进 README 与 docstring）；
   `执行后` = 用例体结束（**无论通过还是失败**）、收尾夹具（登出 / 删文档）尚未开始。
2. **实现只在 `qa/e2e/conftest.py`**：`pytest_runtest_call` 的新式 wrapper 钩子（`wrapper=True`），
   yield 前/后各拍一张 → `allure.attach`。**不用 autouse 夹具**（同 scope 下 autouse 会排在 `logged_in`
   **之前**建立 ⇒ 会在登录前就拍）；`page.screenshot(timeout=5000)` 显式小超时；取 page / 截图 / attach 的
   **任何异常一律吞掉**（钩子本体只有 `try/finally`、不捕获 ⇒ 用例体原始异常原样外抛、失败时「执行后」照拍）。
3. **下游零改动**：`finalize-run.py` 对 `artifacts/allure-results/` 整树 `copytree` 进卷、`allure generate`
   读整目录 ⇒ 附件直接出现在报告 HTML 里，5.5 的链路（脚本 / workflow / 卷布局）一行没动。
4. **文档同步 5 个文件**：`qa/e2e/README.md`（产物路径 / 留痕策略拆两套 / 新增「用例前后截图」小节）、
   `docs/test-cases/TC-05.md`（产物落点）、`docs/design/05-自动化测试.md`（§7.1.4 表 + §7.4.2 理由① 订正，
   三条理由全保留）、`docker-compose/report-nginx/default.conf`（头注同口径订正，**纯注释、无需重建容器**）、
   终端汇总加一行「用例截图」（后两处由主会话复核时补）。
5. **实证（跑在真测试环境，不是桩）**：绿跑 **5/5 通过 / 20.07s**（run_id `20261013T001714Z`）⇒ 10 张附件
   （5 条 × 前后）逐条核对名字与顺序；抽图**人眼核对**（S1 前 = 空白、后 = 控制台；S4 后 = 对话页带回答
   「你好呀！」+ `qwen2.5:7b` 标签）；**受控失败**（故意用错口令跑 S1）⇒ 两张附件照拍、断言原文未被顶掉、
   trace.zip + 整页失败图并存、`cleanup.login=none` 如实；借 builder 镜像 JDK + 缓存 CLI 生成报告 HTML
   （10 张图全在，2.6MB），Windows 浏览器可开。

## 遇到的坑

1. ★ **换行符判据又踩了记忆里警告过的那个坑**：复核时现场拼 `grep -c $'\r'` 判 CRLF，五个文件全部报
   "整文件 CRLF"（计数恰好 = 总行数 ⇒ 模式被展开成空串、每行都匹配的**假阳性**）。改按 memory 的既定做法
   （Python 读字节 + 与 `git show :file` 逐文件比）复测：全部 LF、与 HEAD 一致、无翻动。教训已存过一份仍重演，
   说明"记得别那么干"不如"固定一条命令"。
2. **Windows 侧 venv 有包但没装 Chromium**（`%LOCALAPPDATA%\ms-playwright` 不存在）⇒ README「安装」表的
   B 面（Windows 本地跑）**当前实际不可用**；验证只能走测试发行版脚手架（`$HOME/nexus-e2e-venv`，Chromium 已装）。
3. **测试发行版不挂 `/mnt/c`，代码怎么进去**：`tar czf - --exclude=… -C qa e2e fixtures | wsl -d <distro> -- bash -s`
   喂进 `~/e2e-check/` 脚手架跑 —— 不碰 CI runner 工作区、不 push、跑完整目录可删（判据：产物只落在脚手架里）。
4. **给 Windows 看报告**：distro 内 `python3 -m http.server --bind 0.0.0.0` 被安全策略拦（Expose Local Services）
   ⇒ 改 `--bind 127.0.0.1`，靠 WSL 的 localhost 转发在 Windows 侧拿到 200（顺带把 README「需实测 #3」的
   转发能力验了：**通**）。附件直链同样 200、字节数与远端一致。
5. **"点名单"没画到的第三处同口径表述**：`docker-compose/report-nginx/default.conf` 头注也写着
   "conftest 不 attach"。它是**被 compose 只读挂载的部署契约物**，qa 按边界没碰 —— 派活时只点名了两处文档，
   第三处是靠 agent 回执主动上报才没漏（正是 CLAUDE.md 那条"矛盾要指出来"起了作用）。
