## 做了什么

1. **拍板抽公共库 `qa/scripts/lib/tc-common.sh`** —— 判据**不是** DRY。真正的理由：四份脚本逐字重复的约 270 行里，最不能各写一份的是 **trap 段**，它编码的是一条**实测结论**（「未被 trap 的信号直接终止 bash，EXIT trap 不执行」→ 必须 `trap 'exit 130' INT` / `'exit 143' TERM`）。**若只在某一处修好，其余脚本会静默地带着"Ctrl-C 之后环境里留着白名单键"的缺口。**
   边界：`tc01-expired-token.sh`（纯本地计算夹具）**不并入库** —— 它不共用任何机械动作，且「不依赖仓库布局」是它的一项健壮性；只加 1 行注释指向库里的同名常量。
2. **新增两条**：`tc01-login-then-me.sh`（1.2-4）、`tc01-logout-then-me.sh`（1.2-5）。
3. **两个既有脚本改用库，行为不变** —— 用**逐字节 diff 证明**（见「遇到的坑 2」）。
4. **1.2-5 按 jti 精确分流 ②/③ 两步的日志**：查源码发现第 ③ 步的 warn **带 jti**（`JwtAuthenticationFilter:180`），第 ② 步的两条 warn（`:144` 过期 / `:148` 非法）**不带**。于是「含本次 jti 的行」= **这份 token 的一生**（签发 → 登出 → 之后的鉴权失败），与本次运行一一对应，窗口里混着别的用例的日志也不会误判。
5. **1.2-5 增「登出前基线 `/me`」**（预期 200）：没有它，「登出后 401」与「这个 token 本来就不行」分不开；顺带堵住"logout 根本没要求鉴权、回 200 却什么也没做"这种假通过。
6. **文档**：`TC-01.md` 两条步骤栏改成一行命令 + 说明、各补一行备注、§0 前置条件扩充、头部加「脚本化」说明；`qa/README.md` 目录约定加 `scripts/lib/` 一行 + 铁律 #2 补一句"库里出现期望码就搬回 TC 文档"。
7. 更新自身记忆（新增 `stub-faithfulness.md`）。

## 遇到的坑

1. **⚠️ 桩不忠会「掩盖」它本该帮你看清的行为（本次最重要的坑）。**
   桩的第一版里 `POST /api/auth/logout` **没走过滤器三步**，于是"幂等重登出"回了 **200**；而契约 `docs/api/README.md` §5.3 写的是「无 token / **已失效** → 401」，真后端也确实**先被过滤器拦**（logout 不在白名单里）。
   后果的形状很阴险：**退出码全绿**（0/4/130/143 全符合预期），只有**逐行读输出**才发现 —— 而这一处失真，**恰好掩盖了 1.2-5 清理段本要说明的行为**（"清理段回 401 不是失败"）。
   → 处理：改桩（现返回 401 + 40101），并把教训写进记忆：**桩要复刻契约语义，不是复刻源码里顺手的部分。**
2. **重构的正确性不能靠"我看着没改到"。**
   → 处理：先存**重构前**的干跑输出当 baseline，重构后用**同一套桩**重跑，**只归一化随机项（jti / token 串）后逐字节 `diff -u`**。结果：5 例中 4 例**零行差异**，1 例差 **1 行** —— 库在"没登记任何 jti"时多打一句说明，是**有意**新增，已确认。
3. **`40101` 双来源**（上一轮踩过的坑，本轮是它的正向应用）：第 ③ 步「白名单无此 jti」与第 ② 步「token 非法」**共用一个码**。本轮没有再踩 —— 因为上一轮的教训已经变成设计（**先查这个码有几个产生点**），这里用 jti 分流把两者分开。
4. **`tc01-expired-token.sh` 加了一行注释导致行号漂移**（49 → 52），主会话事后核行号才发现。小坑，记一笔：**跨 agent 交接时引用的行号会因编辑而漂移，引用应带"锚点"（函数名/字符串）而非纯行号。**

## 下次怎么改进

1. **桩要按契约写，不按源码写；而且「干跑通过」不等于「桩忠」。**
   退出码全绿只能证明「脚本按桩的行为走对了」，证明不了「桩和后端行为一致」。**桩的每一处"顺手简化"，都是一处可能掩盖真相的失真。** 具体做法：写完桩后，拿契约文档逐条对一遍**响应码**，而不是只看字段。
2. **重构既有脚本时，一律用 baseline + 归一化 diff 证明等价**，不要用"我看了，没问题"。归一化的对象是**天然的随机项**（jti、token 串、时间戳），其余一律逐字节比。
3. **抽公共库的判据，除了"重复的是机械动作"，还有一条更强的信号：某段代码编码了一条踩过的坑/实测结论。** 那种段绝不能有多份 —— 修一处漏几处的缺口是**静默**的，比代码重复严重得多。
4. **跨 agent 交接引用代码位置时，用锚点（函数名、字符串）而不是纯行号。** 本次一行注释就让行号漂了 3 位。
5. **`--self-test` 里要专门验"取不到的路径必须失败"** —— 本次为 1.2-4 堵的是「取值器坏了 → 两边都空 → 看着反而一致」这个头号假通过形态。
