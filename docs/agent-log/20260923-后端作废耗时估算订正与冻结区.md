## 做了什么

1. ★ **先核代码路径，再决定注释怎么写**：`max-chunks` 校验在「**分块之后、向量化之前**」

   **不会真的跑几十分钟**。⇒ 注释只能写成「**上限存在的理由（反事实）**」，
   而不是让人以为"这类文件会被处理 75 分钟"。
2. **订正 6 处**（全为 Javadoc / 行内注释 / yml 注释）：
   `ResultCode`（定为**代码侧算式的唯一真源**：2 万块 ÷ 16 = **1250 批** × 实测 3.6 s/批 ≈ **75 分钟**，
   并写明"分块一结束就判，**此时还没进事务、一次 embedding 都没调**"）、
   `RagProperties`、`KbDocumentServiceImpl`（类注释的编排图 + 检查点行内）、`KbDocumentService`、
   `KbDocumentController`（`数十秒量级` → `数十秒~两分钟量级`，与契约 §7.1 第 3 条同措辞）、
   `application.yml`（`调了几千次 embedding 之后` → 去掉这个按"每块一次"的旧算法，只留不可漂的表述）。
3. **契约同步：不需要（已双向核对）** —— 逐条过了 `ResultCode` 全部 `msg` 与 `GlobalExceptionHandler` 的出口，
   **无一条 msg 含时长/速率**；反向也核了契约里 10204 的描述与代码一致 ⇒ 两个契约文件**未改**。
4. 算术口径定死：3000 块 = 188 批 ≈ **11 分钟**（与设计 §5.1-4 / §9 风险 14 逐字一致，直接引用未另造数）。

## 遇到的坑

1. ★ **同一病灶还有一处在"冻结区"里，不能就地改。**
   `db-patch/202609221100…sql` 的注释仍引用着旧口径（"587 块 ≈ 90 秒"）。
   处置：**拒绝就地订正**，并给出硬理由 —— 迁移引擎对**已应用**补丁比对 checksum，
   内容一变即 `EXIT_CHECKSUM_MISMATCH`、**退出码 2、迁移终止 ⇒ 后端起不来**（已在 `PatchCli` 核实机制）。
   改由主会话在设计 §0.3 加「冻结区提示」，指明该引用已作废、且**禁止顺手改补丁**。
   ⇒ 教训：**"全域搜索并订正"这类任务必须先划出不可改区**（已发布补丁 / 历史留档），
   否则"顺手改干净"会把环境直接搞挂。
2. **别给"字节数"配耗时估值。** 10MB PDF 的块数**不可预测**（可能早退 10204、也可能接近 3000 块）——
   给"10MB PDF 一个耗时区间"就是重犯同一个错。处置：把这种句式**本身**删掉，
   改成"按块数 + 实测批速率"的算式。
3. **改文本前先分类：Javadoc / 行内注释 / `msg` / 契约。** `msg` 属契约（会进 `Result<T>` 响应体），
   改了必须连带同步 README + openapi 并点名上报。本次核完是"无一条 msg 含时长" ⇒ 契约零改动。
4. **主会话派单里的依据出处也是断言，接受方要核**：派单写"设计 §4.4/§4.10 是那条上限"，
   实际 §4.4 是 TextChunker、§4.10 是异常出口；权威处是 **D15 / §5.1-4 / §9 风险 14 / §6.2 / §3.8**。
   执行者指出后按对的编号引用（本项目"文档自相矛盾必须指出"的又一次落地，这次矛盾在派单里）。
5. **一处"表述不精确但不影响行为"的，按不扩大范围处理**：`TikaDocumentParser.MAX_PARSED_CHARS`（5M 字符）
   只作用于 **PDF 支路**，TXT 支路无此闸，其 Javadoc 读起来像两者都管；实际后果为零
   （10MB TXT 一样会被 10204 明确拒绝）⇒ **不改、上报**，不属"作废的耗时估算"。

## 下次怎么改进

1. **"全域订正"类任务先产出三段清单**：**可改** / **不可改（冻结区：已应用补丁、历史留档）** /
   **需连带同步（契约、设计文档）**。本次执行者的处置（核路径 → 订正 → 双向核契约 → 拒绝改冻结区并上报）
   可直接当模板。
2. **耗时/规模类说明只写"算式 + 实测量"，不写估值区间**；凡要落数字，先问"**这个量取决于什么**"
   （本例取决于**块数**，不取决于字节数）—— 取决于不可预测量的估值，注定要作废。
3. 派"改文本"类任务时把分类写进要求：**Javadoc / 注释 / `msg` / 契约**，类别决定是否连带同步；
   并附一句"若依据出处与实际不符，请指出并按实际引用"。
