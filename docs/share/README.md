# share —— 对外分享素材

> **这个目录是什么**：能讲给**项目外部的人**听的东西 —— 面试口述稿、酒桌段子、技术分享提纲。
>
> **它不是什么（重要）**：**不是项目规范**，不参与验收。`docs/design`、`docs/task`、`docs/test-cases`、`CLAUDE.md` 是权威的 —— **两者冲突时一律以那些为准**，别的文档**不得引用本目录当判据**。
> 这里的文字允许有语气、有停顿、有详略取舍（讲到哪算哪）；判据不能。
>
> **唯一的硬要求：事实不能编。** 每个技术细节都来自真实发生的事，被追问时要能落到具体机制（每篇文末都附「底料」表）。
> **语气、节奏、笑点随便加；「是谁想出来的」「到底有没有发生」不能改** —— 听众里有同行，也可能有能要来仓库链接的人。
>
> **来历**：2026-09-17，逐条手工验收阶段1 认证功能时卡在「过期 token」一条，事后整理成不同场合的讲法。
