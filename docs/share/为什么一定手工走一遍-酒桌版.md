# 酒桌版：AI 给我写了份说明书，我照着做，系统崩了

> **场合**：酒桌 / 闲聊 / 团建 ｜ **时长**：1.5–2 分钟 ｜ **听众**：同行最好，非同行也能听（全文无行话）
> **事实内核与面试版完全一致**，只是讲法不同 —— 底料见文末。

---

## 口述正文

### 【开场：先把钩子扔出去】

我给你们讲个事儿。

我们家 AI 给我写了份**操作手册**，我照着做 —— **系统当场就崩了。**

【停一下。等有人问"然后呢"，再往下】

### 【先撇清：不是代码烂】

不是它代码写得烂。代码挺好的。

是它给我写的那条**操作步骤** —— **它自己从来没执行过。**

### 【一层层挖，这里要有节奏】

我照着手册上写的，去改一个配置项。

**第一步就卡了**：那个配置项的名字，**整个项目里根本不存在**。
手册上白纸黑字写着呢，代码里没有。我全项目搜了一遍 —— **只有手册自己那一行。**

行，那名字不对，我改对呗？

**也不行。** 手册让我填的值是 **0**，而这儿有个防呆设计：这个值**必须是正数**。
填 0 的后果是 —— **登录直接挂，连门都进不去。**

你们品品：**一条步骤上，叠了两个错。**

要不是我一条一条手工走，这俩错能一直躺在那儿 —— **躺到天荒地老。**

### 【转折：放缓，这里是包袱】

好，那我说我改小一点，改成 2 秒，**重启一下服务**总行了吧？

我顺嘴问了 AI 一句：「这个参数怎么改？」

它跟我说：**你不用改。**

我当时就想 —— 不改怎么测？**你逗我呢？**

它说：你这道门卫，是**先看卡过期没，再看卡在不在系统里**。
所以我自己拿同一把钥匙，签一张**已经过期的卡**，递给门卫 —— 不就完了？

我一试，**还真行。**

我原本得**重启整个系统、还得污染别的测试**才能干的事，
它用一段**纯本地的计算**就给办了。

### 【收】

后来我琢磨明白一件事：

**写手册的那位，从来没照着自己写的手册走过一遍。**

它写得又快又漂亮 —— 但**它验不了自己。**

所以我现在有个雷打不动的习惯：**它写的东西，我一条条亲手走一遍。**

【收尾别拔高，就停在这句。有人接话再展开】

## 讲法提示

| 点 | 怎么做 |
|---|---|
| **【开场】** | 说完"系统当场就崩了"就**停住**，别急着解释。**这一停是全场最好用的一停** —— 有人接"然后呢"，故事就活了。 |
| **"你们品品"** | 这是留给听众的参与点，说完扫一眼，等半秒。 |
| **"你逗我呢"** | 这句是**自嘲位**，讲的时候要真带点不服气 —— 后面反转才有劲。 |
| **【收】** | 别加"所以我学到了…"这种总结，会泄气。停在"我一条条亲手走一遍"。 |
| **被打断** | 缩到"开场 + 一句落点"即可：「AI 给我写的手册，我照着做系统崩了 —— 因为它从没跑过自己写的东西。」 |
| **第二遍讲** | 同一个桌不用讲第二遍。有人替你转述时，别纠正细节 —— **让他吹**。 |

## 诚实边界（三条不能碰）

吹牛可以加语气、加停顿、加"我当时就想"，**这三条不能改**：

1. **不是代码有 bug** —— 代码没问题，**是文档**（那份验收清单）。说成"AI 写的代码崩了"是另一件事，同行一听就知道不对。
2. **"不用改环境"那个思路是 AI 给的** —— 不是你自己想出来的。你的功劳是**在真跑之后、卡住的那个点上问出了这个问题**；这个功劳是真的，不用抢别的。
3. **项目是真的** —— 真跑得起来，能给人看。被问"你那个项目我能看看吗"，答"能"。

> 第 2 条看着像吃亏，其实是这个故事最值钱的地方：
> **AI 挖的坑，是"人真的走了一遍"才现形的；而填坑的漂亮解法，是"人问对了问题"才拿到的。**
> 两边各出一半 —— 这比"我一个人全搞定"更经得起追问。

## 底料（有人较真时的事实）

| 说法 | 实际是什么 |
|---|---|
| "操作手册" | 一份手工验收清单（测试用例），逐条跑 |
| "配置项整个项目里不存在" | 文档写 `nexus.jwt.expire-minutes`，代码绑定的是 `nexus.jwt.expire-seconds` |
| "填 0 连门都进不去" | 有效期同时是 Redis 白名单的 TTL，有一条**有意**的正数守卫；填 0 → 登录 HTTP 500 |
| "先看卡过期没，再看卡在不在系统里" | 过滤器判定顺序：① 无 token → ② 验签名与有效期 → ③ 查 Redis 白名单 |
| "签一张已经过期的卡" | 用同一密钥在本地签一个 `exp` 已过期的 token，纯本地计算 |
| "还得污染别的测试" | 改配置要重建后端容器，且生效期间其他用例拿到的 token 也会秒过期 |

## 与面试版的关系

同一件事，两种讲法：

- **面试版**（[`为什么一定手工走一遍-面试口述.md`](为什么一定手工走一遍-面试口述.md)）—— 落点在**工程判断力**，讲"判据自身的缺陷是结构性盲区"。
- **酒桌版**（本篇）—— 落点在**反差与包袱**，讲"写手册的从没走过自己写的手册"。

两篇的**事实、因果、归属完全一致**，只是详略与语气不同。酒桌上讲顺了，面试时那版会自然带上节奏。
